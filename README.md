# MetalloLab

Metallography Learning Lab — Phase 1 mobile app prototype.

## Included
- RTL Persian UI
- Home dashboard
- Course catalogue and lessons
- Interactive quiz flow
- Virtual laboratory scenario
- Microstructure library and detail pages
- Progress/profile page
- Offline local content

## Build
1. Install Flutter SDK and Android Studio.
2. Run `flutter pub get`.
3. Run `flutter run`.
4. Release APK: `flutter build apk --release`.

The official Flutter release documentation describes APK and App Bundle builds: https://docs.flutter.dev/deployment/android
